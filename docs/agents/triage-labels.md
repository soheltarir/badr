# Triage labels

Use these exact GitHub issue labels in `soheltarir/badr` when triaging.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | More information needed |
| ready-for-agent | ready-for-agent | Fully specified for agent work |
| ready-for-human | ready-for-human | Human implementation needed |
| wontfix | wontfix | Will not be actioned |

Ready-for-agent does not override blockers. Use assignment to claim work
and GitHub's closed state to mark resolution; see `issue-tracker.md`.
Preserve existing labels and their descriptions/colors. Create only missing
configured labels.
